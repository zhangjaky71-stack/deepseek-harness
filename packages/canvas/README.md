# canvas/ — generative media Canvas

English | [中文](README.zh.md)

The Canvas group owns the session-scoped generative-media workspace and the media-workflow capabilities that operate on it. The current package establishes the shared domain vocabulary; execution, providers, assets, Agent tools, and browser presentation are added as independent roles when their implementations exist.

| Package | Role |
|---|---|
| [`canvas/`](canvas/README.md) | Shared Canvas snapshot, semantic media-workflow vocabulary, revisions, output references, derived product state, and pure invariants |
