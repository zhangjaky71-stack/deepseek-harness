# N11 implementation — Workflow Editor, Draft, atomic operations, Undo/Redo

Status: in progress

Branch: `agent/canvas-n11-editor-workspace`

## Implemented

- Added `draft.ts`: node-level Inspector Draft, JSON config parsing, atomic operation derivation, inverse command derivation, delete ordering, subgraph copy, fresh-id paste, and WorkflowRef helper.
- Added `store.ts`: session-scoped slot store containing save status, Draft, revision-fenced undo/redo history, clipboard, and transient positions. It intentionally contains no full workflow snapshot.
- Added `adapters.ts`: renderer-neutral workflow/layout projection and layout merge helper. Renderer JSON never enters Domain.
- Replaced the N07 fixed `Saved` skeleton with real `Saved / Saving / Conflict / Offline / Save failed` state.
- Added Host-CAS mutation bridge through the existing N06 `canvas.editWorkflow` Remote. The Browser supplies the exact expected `workflowRevision`; mismatch is a conflict before the write.
- Added Inspector 450 ms autosave. A dirty Draft based on an old projected revision is retained and marked conflict.
- Added Undo/Redo where each accepted inverse/forward operation is a normal Host mutation and therefore creates a new revision.
- Added Copy/Paste/Delete and Select All semantics. Paste creates fresh node/edge ids and commits one atomic batch. Delete disconnects edges before nodes and updates output ids atomically.
- Added draggable semantic node cards. Pointer movement is local; pointer-up writes only `canvas/layout-change` through `saveLayout`.
- Added `canvasFeatures.listNodes()`: a read-only, client-safe catalog projected directly from Host `ctx.mediaNodes`. Zod schemas, execution functions, Provider instances, and other Host-only values never cross the Remote boundary.
- Node Library now creates nodes from registry `defaultConfig`, type/version, lifecycle, feature, UI, and port metadata instead of cloning an existing node.
- Added port-level connection authoring from catalog output/input descriptors. New edges use the existing atomic `connect` operation; selected edges are removed through the existing atomic Delete path.
- Added local validation panel for config JSON and revision conflicts.
- Added tests for Draft operations, copy/paste, delete ordering, inverse commands, layout boundary, and revision-fenced store history.

## Upstream rc.8 interaction

The N11 stack is based on the rc.8 Client compatibility commit `83dad93af0450a5b49d3db76fe36eba47820e176`. It uses the declared slot-store model for presentation state and keeps mode/semantic selection in request-readable injected hook sources because those values are also staged into the next Agent turn's `CanvasInteractionContext`.
