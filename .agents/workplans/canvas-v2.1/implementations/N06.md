## Deliberate API boundaries

Current Canvas and editor-layout reads remain Session Projection-only. N06 does not add `getCurrent`, and Remote mutation results do not become a second current-state source.

Run history is reconstructed from the append-only Session log. The cursor encodes the durable run-start sequence rather than an array offset, so runs appended after a page is returned do not reorder the remaining walk.

Browser callers cannot choose an audit actor or request source. The current single-user Browser attribution uses the owning Session/Agent id as a session-level human surrogate; a later identity layer can replace that id behind the same Host authorization path.
