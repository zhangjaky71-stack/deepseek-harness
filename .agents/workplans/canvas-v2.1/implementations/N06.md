## Delivered

- `CanvasService` remains the single Host authority and Typert namespace `canvas`.
- Browser callable Remote endpoints are limited to implemented behavior: `editWorkflow`, `replaceWorkflow`, `selectOutput`, `saveLayout`, `clear`, `listRuns`, `getRun`.
- Removed future-only `run/cancel/createVariant/restoreWorkflow` from the current callable method-name contract instead of publishing fake endpoints.
- Current Canvas/Layout reads remain Session Projection-only; N06 adds no `getCurrent` RPC.
- Browser wrappers mint Host-owned `human:host-browser + browser-remote` provenance and never accept caller-supplied actor/source.
- Mutation responses are small receipts rather than a second current-state snapshot source.

## Generation-scoped History

- `CanvasRunHistoryEntry` now carries the durable `canvasId` generation.
- `ListCanvasRunsRequest` requires `canvasId`.
- `GetCanvasRunRequest` requires `canvasId + runId`.
- `CanvasRunHistoryIndex` is rebuilt from authoritative Session events and then incrementally updated; queries no longer rescan/sort the whole Session log on every call.
- The index validates the same event prefix through the N03 strict Canvas fold before accepting history rows.
- Per-Canvas buckets prevent clear/recreate generations from sharing query results.
- Exact Run lookup returns `null` when a Run id does not belong to the requested Canvas generation.
- Pagination is newest-first, defaults to 20, caps at 100, and uses an opaque cursor anchored to the durable `run-start` Session sequence.
- History service authorization uses the requested Canvas/Run resource rather than the current Canvas resource, preventing current-generation permission from authorizing an older generation.

## Weak SRC boundary hardening

Generated Typert artifacts remain the strict schema boundary when present, but source-mode descriptors only guarantee JSON-safe values. N06 therefore adds Host runtime guards before authorization/business logic for:

- `WorkflowRef`
- workflow edit operation shapes and exact operation fields
- `SelectCanvasOutputRequest`
- `SaveCanvasLayoutRequest`
- `ListCanvasRunsRequest`
- `GetCanvasRunRequest`
- replacement `MediaWorkflow`

Malformed weak-mode payloads fail loud as Canvas business validation instead of falling through to incidental `TypeError` behavior.

## Remote error safety

Typert protocol now has explicit `TypertBusinessFailure` as the opt-in public business-error carrier. Gateway behavior is frozen as:

- transport cancellation → `cancelled`
- `TypertBusinessFailure` → its bounded/frozen public failure
- `TypertLookupFailure` → adapter-owned failure
- every other exception → `internal / Remote request failed / {}`

The Gateway no longer copies ordinary `Error.message` into the Browser response.

`CanvasServiceError` and History query errors remain Host `HarnessError`s. Browser Remote wrappers map only allowlisted Canvas codes to fixed public messages before constructing `TypertBusinessFailure`; resource ids, policy diagnostics, raw Provider text, and arbitrary internal messages are not exposed by this path.

## Derived-cache atomicity

`CanvasService.sync()` now clones both current Canvas fold state and the rebuildable History index, applies the entire unseen Session-event batch to the staged copies, and publishes both only after the batch succeeds. A History/index bug therefore cannot leave the cache in a half-advanced state where Canvas and History disagree.

## Shipped invariant composition

The base profile now mounts:

- `@deepseek-ai/dsh-invariants`
- `@deepseek-ai/dsh-canvas`
- `@deepseek-ai/dsh-canvas/invariant`

`@deepseek-ai/dsh-invariants` is a real `dsh-base` runtime dependency rather than peer/dev-only. This makes N03/N04's one-shot Canvas write permit part of shipped composition: current direct Session append without the package permit is rejected during precommit, while normal `CanvasService` commits use the permit.

A Loader-driven composition test mounts the actual invariant registry/Canvas/companion plugin set and checks direct current append rejection plus successful CanvasService create/edit. The base bundle test separately pins the shipped rows and dependency/order contract.
