## Architecture decisions

Canvas current state remains projection-owned. N07 introduces no browser Canvas store, no client-side replay fold, and no `getCurrent` request.

Minimal/Editor mode is presentation-only and therefore browser-local. It does not consume the Canvas Remote namespace and cannot append a Session event.

The Canvas domain's product-state function is not imported as a Browser runtime value. The Web shell uses an isomorphic pure copy of the N01 rules because `dsh-canvas` is a Host package, not a browser module contribution. Tests pin the copied behavior across all eight states.

The ordinary Conversation Shell remains the page owner. Canvas is one body view and the resident composer remains outside the view ring, preserving ordinary prompt entry while Canvas is selected.
