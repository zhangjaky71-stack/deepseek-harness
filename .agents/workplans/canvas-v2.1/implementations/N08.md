## Delivered before this remediation slice

The current N07-compatible stack already contained most of the N08 functional path:

- a per-session Browser-local `CanvasInteractionStore` for node, edge, durable asset, focused-output, and region selection;
- generation/workflow/revision anchors so revision-only drift can remain stale while clear/re-create or workflow replacement cannot silently rebind selection;
- `conversation.registerPromptPreparation` integration that snapshots selection only at ordinary prompt send time;
- exact prompt RPC-id staging through the generated `canvasInteraction` Remote;
- Host binding from the admitted prompt RPC id to the exact inserted user-message id;
- `agent/pre-step` injection immediately before the matched user message, using a normal logged plugin-context message;
- reject/discard/agent-dispose/plugin-dispose cleanup plus bounded staging TTL;
- execution-time staleness re-evaluation;
- Session-history validation for selected durable asset references;
- deployment feature gating for Canvas and region selection.

The historical `agent/canvas-n08-interaction-context` branch is no longer a valid continuation base: it is far behind the remediated N07 stack. This node therefore uses a fresh remediation branch based directly on `fix/canvas-n07-v2.2-dynamic-surface` and preserves the historical branch unchanged.

## Remediation delivered in this branch

### Strict Remote envelope admission

`CanvasInteractionBridge.stage()` and `discard()` now accept the Remote payload as untrusted runtime input. Before any Host Canvas read or correlation-state mutation they require an object envelope and reject unknown top-level fields. `rpcId` remains bounded to the transport-safe character set.

`CanvasInteractionService.remoteExportStage()` no longer dereferences `request.context.region` before runtime decoding. Region feature policy is applied to the already-decoded interaction context through the bridge validation hook. This prevents malformed weak-SRC payloads such as `null`, arrays, or unexpected shapes from escaping as raw JavaScript `TypeError`s before the Canvas Remote error boundary.

### Model-visible identifier budget

The interaction decoder now places an explicit boundary on identifiers that can be rendered into the Agent-visible plugin-context message. Canvas, workflow, node, edge, run, image-attachment, and video-asset identifiers are limited to 256 characters and to a single-line opaque identifier character set. Newline/control-text and oversized identifiers are rejected during interaction admission rather than interpolated into model-visible text.

This is intentionally narrower than the general durable Canvas identifier type: N08 owns the Browser-to-model context channel and therefore applies a stricter model-facing budget without retroactively changing N01–N06 durable schema compatibility.

### Regression coverage

`interaction-bridge.spec.ts` now proves malformed/null/array/extra-field stage/discard envelopes fail before Host business reads, invalid RPC ids keep their stable code, and decoded-context policy executes before Host projection access.

`interaction.spec.ts` now proves control-text and oversized model-visible identifiers fail strict interaction decoding, including selected node and selected durable asset identifiers.

## Authority and lifecycle conclusions

Interaction selection remains presentation-only. It is not written as `canvas/change`, does not advance Workflow revision, and is not a Session Projection authority. Only the context actually consumed by an Agent turn becomes durable, through the repository's ordinary logged plugin-message path.

The correlation bridge remains keyed by Agent identity plus exact prompt RPC/message identity, with prompt reject/discard, Agent disposal, plugin disposal, and TTL cleanup. Browser client state remains keyed by Session identity and is pruned when Sessions leave the client catalog.

## Deliberate boundaries

N08 does not implement visual mask drawing, DAG mutation, media execution, provider routing, retries/cancellation, or a second Canvas-specific chat transport. Region selection remains only a DTO/store seam for later editor nodes.

Stale workflow selections are still admissible by design: they are rendered as `STALE` and require `canvas_read` before acting. N08 does not silently upgrade a sampled revision to the current one.
