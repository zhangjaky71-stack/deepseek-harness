## Open-world node-type correction

N10 exposed a pre-existing contradiction: Canvas Domain and Migration still used a closed seven-type whitelist, so a third-party node could register metadata but its durable workflow value could not survive the pure Canvas boundary. N10 removes that contradiction without changing the Canvas schema/event version.

- `MediaWorkflowNodeType` now derives from declaration-mergeable `MediaWorkflowNodeTypeMap`. A node package can add a typed identifier without editing the Canvas package.
- Pure Canvas Domain validation now treats node `type` as a stable non-empty semantic identifier and continues validating node id/version/config plus graph identity relationships. Registry recognition is no longer a durable-domain invariant.
- N02 migration remains strict for known built-in node versions through `MEDIA_WORKFLOW_NODE_VERSIONS`.
- Unknown/plugin node types are preserved with a positive integer `nodeVersion` and are never guessed/migrated by core Canvas code.
- Therefore uninstalling or temporarily omitting a node plugin does not make historical Session data undecodable. The workflow opens, while `ctx.mediaNodes` fails loud with `MEDIA_NODE_UNKNOWN_DEFINITION` when a current consumer tries to create/validate/execute an unavailable definition.

This separation is required for plugin HMR, rollout/rollback, historical replay, and future external node packages.

## Lifecycle semantics

Intrinsic lifecycle and deployment capability are separate axes.

- `deprecated=true` may coexist with `creatable=false` and `executable=true`: historical nodes remain usable while new authoring is blocked.
- `executable=false` is an intrinsic hard block exposed through `ctx.mediaNodes.assertExecutable()`; N12 must include that check in full workflow validation/execution admission.
- N09 deployment feature state is not copied into registry state. A definition can require `feature: 'video'`; consumers combine that static requirement with `ctx.canvasFeatures` at the use boundary.
- Definition removal is process-local metadata removal only. It never appends Canvas events or rewrites historical workflows.
