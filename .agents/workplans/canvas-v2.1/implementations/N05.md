## Delivered

- Added client-safe `SessionProjectionMap` entries for `canvas` and `canvasLayout` through `@deepseek-ai/dsh-canvas/client`.
- Added whole-value Canvas and layout projection folds with fail-soft malformed-event handling and same-reference behavior for unrelated events.
- Registered both projection units from the existing CanvasService lifecycle whenever `ctx.sessionProjections` is composed, so HMR/service disposal removes both registrations.
- Added independent durable `canvas/layout-change` events carrying one complete `CanvasLayoutSnapshot` plus current N04 audit metadata.
- Added strict layout decoding, geometry/timestamp validation, layout replay fold, and current-workflow relationship checks in the package invariant.
- Added `CanvasService.saveLayout()` with Host `canvas.layout.write` authorization, workflow-id and current-node validation, server-side monotonic timestamping, and one Session append.
- Kept semantic workflow/run revisions unchanged by layout writes.
- Preserved current layout across semantic workflow edits while resetting the current `canvasLayout` projection on Canvas create/clear; historical layout events remain in the Session log.
- Kept projection payloads bounded to current Canvas/current layout rather than run history, provider raw responses, logs, binary media, or progress history.
- Added focused projection/layout/invariant coverage for live state, cold replay, refresh behavior, HMR disposal, permission denial, mismatched workflows, unknown nodes, and boundedness.
- Updated the bilingual package README and Session media Canvas Agent Note with the projection/layout current-state contract.
